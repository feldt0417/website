autoexec.cfg

How to install

  1. Save the file to Steam\steamapps\common\Counter-Strike Global Offensive\game\csgo\cfg\
  2. In Steam, right-click CS2 → Properties → Launch options and add +exec autoexec
  3. Launch the game. Your settings load every time.

FAQ

Questions, answered

Can't find what you need? The tools themselves include step-by-step install notes.

Can FragLab get me VAC banned?

No. FragLab never interacts with the game. It generates console commands and .cfg files that only use Valve's own built-in settings, the same ones you could type into the console yourself.

Where do I put my autoexec.cfg?

Save it to Steam\steamapps\common\Counter-Strike Global Offensive\game\csgo\cfg\. Then, in Steam, right-click CS2 → Properties → Launch options and add +exec autoexec.

How do I load the practice config?

Save practice.cfg to the same cfg folder. In game, open the console, type map de_mirage (or any map) to start a local server, then run exec practice.

How accurate is the crosshair preview?

At 1× zoom, the preview approximates how the crosshair looks on a 1080p screen. The exact pixels depend on your resolution and aspect ratio, so give it a quick check in game before a match.

Can I import a crosshair share code (CSGO-xxxxx)?

Not yet. Share-code support is planned. For now, paste your cl_crosshair… console commands into the importer. You can also import share codes directly in CS2 under Settings → Game → Crosshair.

Why does the sensitivity converter only list some games?

FragLab only lists games with a fixed, known yaw (degrees turned per mouse count). That's what makes an exact conversion possible instead of a guess.
