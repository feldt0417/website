Features

Everything you need, nothing you don't

One small app that handles the fiddly parts of your CS2 setup, so you can get back to playing.

Bhop helper

Hold one key to chain jumps. Pick your activation key and switch between hold and toggle modes.

Crosshair editor

Design your crosshair with a live preview, then apply it or copy the console commands.

Config profiles

Save setups for matchmaking, practice or community servers and swap between them in a click.

Speed overlay

See your horizontal speed while you move, so you can tell exactly when your hops are clean.

Custom hotkeys

Bind every feature to the keys you want. Rebind anything in seconds, right next to each feature.

Light on resources

Sits quietly in your tray and stays out of the way of your frames.

autoexec.cfg

How to install

  1. Save the file to Steam\steamapps\common\Counter-Strike Global Offensive\game\csgo\cfg\
  2. In Steam, right-click CS2 → Properties → Launch options and add +exec autoexec
  3. Launch the game. Your settings load every time.

How to use

  1. Save practice.cfg to the same cfg folder as your autoexec.

Where can I use the bhop helper?

Use it on community servers whose rules allow it, like many bhop and surf servers, or on your own practice server. KZ servers ban bhop scripts. Valve doesn't allow movement automation on official matchmaking servers, so keep it switched off there.

Which systems does FragLab run on?

Windows 10 and Windows 11, 64-bit.

Do the web tools need the app?

No. The crosshair builder, sensitivity converter and config generators on this page run entirely in your browser. Nothing is uploaded anywhere.

Where do I put autoexec.cfg and practice.cfg?

Save them to Steam\steamapps\common\Counter-Strike Global Offensive\game\csgo\cfg\. Add +exec autoexec to CS2's launch options in Steam. For practice, start a local map with map de_mirage and run exec practice.

How do I get updates?

FragLab can check for updates on launch (you can turn this off in Settings). New releases are also announced in the Discord.

Is FragLab affiliated with Valve?

No. FragLab is an independent project and isn't affiliated with or endorsed by Valve Corporation.
